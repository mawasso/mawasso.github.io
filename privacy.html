Privacy policy

SHOGUN Home Assistant is for personal use only, by a single household.

  • It uses Google sign-in only to let the household's own Home Assistant server read and control the household's own Google Nest devices.
  • Device data stays on the household's own Home Assistant server at home.
  • No data is sold, shared with anyone else, or used for advertising.
  • Access can be removed at any time in the Google account's security settings, under third-party connections.
